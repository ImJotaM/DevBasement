# DevBasement

Um gerenciador de projetos para desenvolvedores.

## Proposta

Uma plataforma que permite que o usuário crie projetos e organize dentro deles itens como repositórios do GitHub, links de documentação, arquivos markdown, snippets de código e textos. O usuário pode tornar seus projetos públicos para que outras pessoas possam comentar, curtir, fazer perguntas e apoiar o desenvolvimento do projeto.

## Funcionalidades planejadas

- Perfil de usuário com informações pessoais e links
- Criar, editar e deletar projetos
- Adicionar diferentes tipos de itens em cada projeto
- Projetos públicos e privados
- Sistema de curtidas e comentários
